# Goals

## Infrastructure

This area matters because stable infrastructure makes every other system easier to trust and operate.

Skills being developed:
- Multi-node virtualization
- Storage planning
- Lifecycle management
- Operational documentation

Long-term capability:
- Run a homelab that resembles a small production environment.

## Networking

This area matters because routing, DNS, and remote access shape everything else.

Skills being developed:
- Routing
- Subnetting
- DHCP
- DNS
- Remote access

Long-term capability:
- Design and operate a secure network with clear trust boundaries.

## Virtualization

This area matters because Proxmox is the compute substrate for the environment.

Skills being developed:
- Cluster operations
- VM lifecycle management
- Storage awareness
- Snapshots and recovery

Long-term capability:
- Manage the cluster with production-style discipline.

## Identity

This area matters because identity is the foundation of secure access.

Skills being developed:
- Active Directory
- OU design
- Role-based access
- User lifecycle management

Long-term capability:
- Build an identity model that supports growth and separation of duties.

## Linux

This area matters because Linux services will support automation and future applications.

Skills being developed:
- SSH administration
- Service management
- Permissions
- Automation

Long-term capability:
- Administer Linux systems confidently and repeatably.

## Windows

This area matters because Windows Server and client systems remain core to the lab.

Skills being developed:
- Domain services
- Workstation management
- DNS integration
- Enterprise administration patterns

Long-term capability:
- Operate Windows infrastructure with the same rigor as other platforms.

## Containers

This area matters because containerized services make future applications easier to deploy and recover.

Skills being developed:
- Docker
- Persistent data handling
- Secrets management
- Update planning

Long-term capability:
- Deploy internal services cleanly and recover them reliably.

## Monitoring

This area matters because visibility is required for good operations.

Skills being developed:
- Metrics
- Logging
- Alerting
- Health validation

Long-term capability:
- Detect and explain infrastructure degradation early.

## Security

This area matters because the lab should demonstrate sound judgment, not just functionality.

Skills being developed:
- Least privilege
- Secret hygiene
- Segmentation
- Secure remote administration

Long-term capability:
- Maintain a secure public-facing documentation posture and a secure internal environment.

## Automation

This area matters because repeatability reduces errors and improves consistency.

Skills being developed:
- PowerShell
- Bash
- Ansible
- Provisioning logic

Long-term capability:
- Automate recurring operations and reduce configuration drift.

## Development

This area matters because OwlHQ and related tooling connect infrastructure to software delivery.

Skills being developed:
- Service design
- Data normalization
- Internal tooling
- Docker-based deployment

Long-term capability:
- Build internal applications that support operations rather than obscuring them.
