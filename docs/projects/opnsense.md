# OPNsense

## Scope

Document the firewall and routing layer in a way that is safe to publish.

## Topics to Include

- Firewall goals
- Segmentation strategy
- VPN usage at a high level
- DHCP and DNS roles
- Logging and monitoring
- Rules or policies described generically

## Do Not Include

- Rule numbers tied to sensitive systems
- Public-facing endpoints
- VPN secrets or configuration exports
- Admin access details

## Notes

Focus on design decisions, lessons learned, and outcomes rather than exact configuration.
